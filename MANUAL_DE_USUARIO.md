# Manual de Usuario Oficial — Al Lado ("Top Trading")

¡Bienvenido a **Al Lado**! Tu plataforma y marketplace geolocalizado para conectar con comercios, servicios y anuncios de tu comunidad de forma rápida, sencilla y cercana.

---

## 📱 1. Primeros Pasos: Acceso y Registro

Al abrir la aplicación por primera vez, podrás ingresar a tu cuenta de forma segura mediante dos métodos:
1. **Google Sign-In:** Un toque rápido para iniciar sesión con tu cuenta de Google.
2. **Correo Electrónico:** Ingresando tu email y contraseña habituales.

Una vez dentro, la pantalla principal te mostrará el **Feed de Anuncios** y el **Mapa Interactivo** con todo lo que sucede a tu alrededor.

---

## 🛒 2. ¿Cómo Comprar en una Tienda?

Si quieres adquirir productos de los comercios locales adheridos a Al Lado, sigue estos simples pasos:

```
[ Explorar Inicio / Mapa ] ──► [ Buscar Tienda o Producto ]
                                          │
                                          ▼
                               [ Ver Detalle de Tienda ]
                                          │
                                          ▼
                               [ Seleccionar Producto ]
                                          │
                                          ▼
                              [ Agregar al Carrito (TTL 72h) ]
                                          │
                                          ▼
                             [ Revisar Carrito y Total ]
                                          │
                                          ▼
                            [ Confirmar Pedido y Pago ]
```

1. **Busca la tienda** desde la barra de búsqueda o muévete por el mapa interactivo.
2. **Explora el catálogo** de productos disponibles en esa tienda.
3. **Selecciona el producto** que deseas y presiona **"Agregar al Carrito"**. (Recuerda que tus productos se guardan en el carrito durante un tiempo límite de 72 horas).
4. Ve al **Carrito**, revisa los montos totales (puedes alternar entre USD y CUP según la tasa de cambio vigente) y **confirma tu pedido**.
5. ¡Listo! El comercio recibirá tu solicitud de compra para procesarla.

---

## 🏪 3. ¿Cómo Vender y Crear tu Tienda?

Si tienes un negocio o comercio y quieres ofrecer tus productos en Al Lado, puedes crear tu propia tienda virtual:

```
[ Ir a Perfil / Menú ] ──► [ Quiero Vender / Crear Tienda ]
                                      │
                                      ▼
                        [ Onboarding: Datos del Comercio ]
                        (Nombre, Categoría, Municipio, Ubicación)
                                      │
                                      ▼
                        [ Seleccionar Plan de Tienda ]
                        (Gratis / Basic / Premium)
                                      │
                                      ▼
                        [ Enviar Solicitud a Revisión ]
                                      │
                         (Aprobación por el Administrador)
                                      │
                                      ▼
                        [ ¡Tienda Activa! Panel Vendedor ]
                        (Gestiona productos, stock y QR de pago)
```

1. Dirígete a tu sección de perfil y selecciona la opción de **Crear Tienda**.
2. Completa los datos básicos de tu negocio (nombre, categoría, descripción y ubicación en el mapa).
3. Selecciona el **Plan** que mejor se adapte a tus necesidades (Gratis, Basic o Premium). Cada plan determina tu límite de productos y ranuras de anuncios.
4. Envía la solicitud. Tras una rápida revisión por parte de la administración, tu tienda quedará **Activa** y tendrás acceso al **Panel de Vendedor** para cargar tus productos y configurar tus códigos QR de pago.

## 📢 4. ¿Cómo Publicar un Anuncio?

Al Lado te permite promocionar artículos puntuales o tu negocio mediante tres tipos de anuncios:

```
[ Sección Anuncios ] ──► [ Botón Publicar / Crear Anuncio ]
                                    │
                                    ├─► Opción A: Anuncio Independiente (Standalone)
                                    ├─► Opción B: Promoción de Negocio (Barbería, Taller...)
                                    └─► Opción C: Ranuras Extra de Tienda Comercial
                                    │
                                    ▼
                     [ Completar Título, Texto e Imágenes ]
                                    │
                                    ▼
                     [ Seleccionar Paquete y Duración ]
                                    │
                                    ▼
                     [ Enviar a Moderación ] ──► [ ¡Aprobado y Visible en el Feed! ]
```

1. Entra a la pestaña de **Anuncios** y presiona el botón para crear uno nuevo.
2. Elige el **tipo de anuncio**:
   - **Independiente (Standalone):** Ideal si quieres vender algo puntual (una bicicleta, un mueble) sin necesidad de tener una tienda creada.
   - **Negocio:** Para promocionar servicios profesionales, talleres, barberías, eventos, etc.
   - **Tienda:** Si tienes una tienda comercial activa y deseas destacar productos específicos.
3. Rellena el título, descripción detallada, añade fotos desde tu cámara o galería y define el tiempo de vigencia.
4. Selecciona el paquete de anuncio correspondiente y envíalo. Una vez verificado por el sistema, aparecerá publicamente en el feed principal.

## 🤝 5. ¿Cómo Funciona el Programa de Afiliados?

¿Quieres ganar comisiones recomendando la plataforma? Conviértete en afiliado:

```
[ Sección Afiliados ] ──► [ Registrarse como Afiliado ]
                                    │
                                    ▼
                         [ Obtener Código Único ]
                                    │
                                    ▼
                     [ Compartir Enlace con Amigos y Comercios ]
                                    │
                                    ▼
                     [ Nuevos Usuarios se Registran con tu Código ]
                                    │
                                    ▼
                     [ Comisión Acreditada Automáticamente ]
                                    │
                                    ▼
                     [ Solicitar Retiro de Fondos ]
```

1. Regístrate en la sección de **Afiliados** para obtener tu código y enlace personalizado de recomendación.
2. Comparte tu enlace con dueños de tiendas o nuevos compradores.
3. Cuando un comercio se registra o adquiere un plan utilizando tu código de afiliado, el sistema calcula y acredita tu comisión de forma automática.
4. Consulta tus ganancias y solicita retiros directamente desde tu panel de afiliado.

---

## 🗺️ 6. ¿Cómo Funciona el Mapa Interactivo?

El mapa de Al Lado está integrado directamente con OpenStreetMap para ofrecerte una experiencia fluida y sin restricciones:
- **Tu Posición Actual:** La app utiliza el GPS de tu dispositivo para centrarse automáticamente en tu ubicación geográfica.
- **Pines Cercanos:** Verás iconos flotantes que representan las tiendas y negocios registrados a tu alrededor.
- **Acceso Directo:** Toca cualquier pin en el mapa para ver una tarjeta flotante con el nombre del comercio, su logo y un acceso directo para entrar a su tienda y ver lo que ofrecen.
